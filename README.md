Minimalistic, fully offline app to track tasks or chores in.

Right now only on Android via the .apk file in releases

## Features
 - **UI**
    - minimalistic monochrome UI with smooth animations
 - **Local**
    - slopless app completely offline without any data send anywhere
 - **Simple**
    - simple way of taking notes, adding details, marking them as done
